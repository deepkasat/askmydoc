## 🌟 What It Does

AskMyDoc lets you have a conversation with your documents. Instead of reading through lengthy PDFs manually, you upload the file and instantly get:

- A concise **3-4 sentence summary**
- **5 key insights** extracted from the document
- A **chat interface** to ask any question about the content in natural language

Built to demonstrate full-stack + AI integration skills for software engineering roles.

---

## ✨ Features

- 🔐 **Authentication** — Register, login, and logout with JWT-based auth and persistent sessions.
- 📄 **Document Upload** — Supports PDF and TXT file formats.
- 🤖 **AI Analysis** — Instant summary and 5 key points generated by LLaMA 3.1 via Groq API.
- 💬 **Document Chat** — Ask follow-up questions and get context-aware answers.
- 📁 **Multiple Documents** — Upload and switch between multiple documents in one session.
- 💾 **Persistent Storage** — User accounts stored in SQLite, survive server restarts.
- ✅ **Toast Notifications** — Auto-dismissing success messages for register, login, and logout.

## 🚀 Getting Started

### Prerequisites
- Node.js v20+
- Python 3.12+
- A Groq API key (free at [console.groq.com](https://console.groq.com))

### 1. Clone the repository

```bash
git clone https://github.com/deepkasat/askmydoc.git
cd askmydoc
```

### 2. Backend Setup

```bash
cd backend
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Mac/Linux

pip install -r requirements.txt
```

Create a `.env` file inside the `backend` folder:

```env
GROQ_API_KEY=your_groq_api_key_here
SECRET_KEY=your_secret_key_here
```

Start the backend server:

```bash
python -m uvicorn main:app --reload
```

Backend runs at: `http://127.0.0.1:8000`

### 3. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend runs at: `http://localhost:5173`

## 🧠 How the AI Works

1. When a document is uploaded, the text is extracted. (PyPDF2 for PDFs)
2. The extracted text is sent to **LLaMA 3.1** via the **Groq API** with a structured prompt.
3. The model returns a summary and exactly 5 key insights.
4. For each chat message, the full document context is included in the system prompt so the model can answer accurately.
5. Conversation history is maintained per document so follow-up questions work correctly.

---

## 🔒 Security

- Passwords are hashed using **bcrypt** before storage — plain passwords are never saved.
- All protected routes require a valid **JWT token** in the Authorization header.
- Tokens expire after **24 hours**
- API keys are stored in `.env` and never committed to version control.
